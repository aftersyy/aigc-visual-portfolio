# 刘洋 · AIGC 视觉与设计作品集

科研、游戏、机器人、工作项目与风格探索的视觉作品展示。

这是 2026-11-11 从网站最新公开数据导出的静态展示版，保留当时的文字、图注、图片顺序和可见作品。已下架的项目与未被可见作品引用的文件未纳入发布包。

## 发布

GitHub Settings → Pages → Deploy from a branch → main / (root)。发布成功后分享 Pages 网页地址，而不是源码仓库地址。也可将本目录部署到 Netlify。

## 后续更新

此展示版不包含服务端管理后台。原网站后台可以继续使用；后台保存的后续修改需要重新导出并同步到此仓库。
